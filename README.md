# AToQcritics — Пошаговая инструкция запуска (бесплатно, для новичков)

Этот проект уже настроен на работу с **бесплатной облачной базой данных PostgreSQL (Supabase)** и **бесплатным хостингом (Render)**. Вам не нужно писать код или настраивать SQL-таблицы вручную — сервер создаст их сам при первом запуске.

## Шаг 1. Создайте бесплатную облачную базу данных (Supabase)
1. Перейдите на https://supabase.com/ и зарегистрируйтесь (можно через GitHub).
2. Нажмите **New Project**, придумайте название (например, `atoqcritics`) и **пароль базы данных** (сохраните его в блокнот!). Выберите ближайший регион (например, Frankfurt) и нажмите **Create new project**.
3. Подождите ~1 минуту. Наверху нажмите кнопку **Connect** → выберите вкладку **Transaction pooler** (или **Session pooler**) и скопируйте строку **URI**.
4. В этой строке замените `[YOUR-PASSWORD]` на пароль, который вы придумали на шаге 2. Это и есть ваш `DATABASE_URL`.

## Шаг 2. Получите бесплатный ключ Steam (Steam Web API Key)
1. Перейдите на https://steamcommunity.com/dev/apikey и войдите в свой аккаунт Steam.
2. В поле «Имя домена» напишите `atoqcritics.onrender.com` (или любое другое имя — Steam не проверяет его строго), поставьте галочку и нажмите **Зарегистрировать**.
3. Скопируйте выданный ключ — это ваш `STEAM_API_KEY`.

## Шаг 3. Загрузите файлы на GitHub
1. Зарегистрируйтесь на https://github.com/ и нажмите **New repository** (назовите `atoqcritics`, выберите Public или Private).
2. Распакуйте этот ZIP-архив на компьютере.
3. На странице созданного репозитория нажмите **uploading an existing file** и перетащите туда все файлы из папки `atoqcritics-fullstack` (включая папку `public`). Нажмите **Commit changes**.

## Шаг 4. Запустите сайт бесплатно на Render
1. Перейдите на https://render.com/ и войдите через GitHub.
2. Нажмите **New +** → **Web Service** → выберите ваш репозиторий `atoqcritics`.
3. Проверьте настройки:
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free` ($0/мес)
4. Прокрутите ниже до блока **Environment Variables** и добавьте 4 переменные:
   - `STEAM_API_KEY` = ключ из Шага 2
   - `DATABASE_URL` = строка подключения из Шага 1
   - `SESSION_SECRET` = любая случайная строка (например `atoq_super_secret_982341_kz`)
   - `BASE_URL` = сначала оставьте `https://atoqcritics.onrender.com` (после создания Render покажет ваш точный адрес вида `https://имя.onrender.com` — если он отличается, обновите `BASE_URL` на точный адрес без слэша в конце).
5. Нажмите **Create Web Service**. Через 2–3 минуты сайт заработает по вашей ссылке!

## Шаг 5. Проверка библиотеки Steam
Чтобы сайт видел купленные игры и часы в них, у пользователя в Steam должно быть открыто:
**Профиль Steam → Редактировать профиль → Приватность → Информация об играх → Открытый**.
